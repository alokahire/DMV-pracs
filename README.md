# ML and DMV Practicals

Executed Jupyter notebooks for Computer Laboratory I practicals.
Every notebook is fully run, with code and outputs visible in each cell.
Each experiment has its own folder (ex1, ex2, ...) holding its notebook and its dataset.

## ML (Machine Learning)
- ex1: PCA on Wine dataset (Wine.csv)
- ex2: Uber Fare Regression (uber.csv)
- ex3: SVM on Handwritten Digits (digits.csv)
- ex4: K-Means Clustering on Iris (iris.csv)
- ex5: Random Forest on Car Evaluation (car.csv)
- ex6: Maze Exploration with Q-Learning (no dataset, RL environment)
- ex6b: Taxi Problem with Q-Learning (extra, no dataset)
- ex7: Emotion Detection from Text (emotion.csv)
- ML_Questions_Answers.md: viva questions and answers for each experiment

## DMV (Data Modeling and Visualization)
- ex1: Data Loading from CSV, Excel and JSON (sales.csv, sales.xlsx, sales.json)
- ex2: Weather Data Analysis using Web API (weather.csv)
- ex3: Data Cleaning on Telecom Churn Data (churn.csv)
- ex4: Data Wrangling on Real Estate Data (realestate.csv)
- ex5: Visualization with Matplotlib, AQI (aqi.csv)
- ex6: Data Aggregation on Retail Sales (retail.csv)
- ex7: Time Series Analysis on Stock Data (stock.csv)
- DMV_Questions_Answers.md: viva questions and answers for each experiment
